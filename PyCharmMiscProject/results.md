## 주요 오인식 패턴 분석

| 패턴 유형 | 예시 | 원인 | 적용된 교정 방법 |
|-----------|------|------|----------------|
| 숫자-영문 혼동 | `50Omg` → `500mg` | 대문자 O와 0 혼동 | 정규식 `(\d)O` → `\g<1>0` |
| 음절 오인식 | `캠술` → `캡슐` | 'ㅍ' vs 'ㅁ' 획 혼동 | CHAR_CORRECTIONS 딕셔너리 |
| 저신뢰 단어 | `비임밥` → `비빔밥` | '빔' 음절 획 복잡성 | difflib 유사도 매칭 |
| 공백 삽입 | `일    시` → `일시` | 자간 넓은 글자 분리 | 이미지 렌더 스케일 2× |
| 한자·특수문자 | 의학 코드 `(I10)` | 괄호 내 숫자/문자 | 도메인 사전 보완 |

## 파이프라인 구성

```
샘플 이미지 생성 (Pillow, S=2.0 렌더링)
   ↓
전처리: UnsharpMask(radius=1.5, percent=130, threshold=3)
   ↓
EasyOCR (en+ko, decoder=greedy, mag_ratio=1.0,
          contrast_ths=0.05, adjust_contrast=0.7, width_ths=0.6)
   ↓
후처리 1단계: CHAR_CORRECTIONS (캠술→캡슐) + regex (50O→500)
   ↓
후처리 2단계: difflib.get_close_matches (도메인 사전, cutoff=0.55)
   ↓
평가: 키워드 검출률 × 평균 신뢰도 → PASS / PARTIAL / FAIL
```
