# RAG 조회 경로와 Langfuse 자동 점수

## 사용자 요청이 RAG까지 가는 API

| API | 역할 | 실제 조회 흐름 |
|---|---|---|
| `POST /records` | 처방전 업로드 | OCR 후 검토가 필요 없으면 `run_rag()`까지 이어져 복약·생활습관 가이드를 저장한다. |
| `POST /records/{record_id}/confirm` | OCR 결과 확정 | 사용자가 확정한 약품명·진단명으로 `run_rag()`를 호출하는 주 경로다. |
| `POST /rag/test/{record_id}` | RAG 단독 점검 | 저장된 OCR 결과로 가이드 생성만 다시 시험하는 개발·진단용 경로다. |
| `GET /ocr/drug-info?drug_name=...` | 약 상세정보 | e약은요·의약품 허가정보·DUR 마스터를 조회해 주의사항, 부작용, 상호작용, 보관법을 보강한다. |
| `POST /chat/ask` | 챗봇 일반 응답 | 생활습관 질문은 질병관리청 문서를, 약 질문은 의약품 문서를 우선 검색하고 DUR 근거를 합친다. |
| `POST /chat/ask/stream` | 챗봇 스트리밍 응답 | `/chat/ask`와 같은 RAG/DUR 입력 수집 경로를 사용하고 답변만 스트리밍한다. |

`GET /records/{record_id}`는 RAG를 새로 실행하는 API가 아니다. 이미 DB에 저장된 가이드와 출처를 읽어 화면에 전달한다.

## 가이드 생성 내부 흐름

1. 약품명은 정확한 상품명 검색을 먼저 하고, 없으면 용량·제형을 뺀 후보명, 로컬 공공 API 마스터, 벡터 유사도 검색 순으로 근거를 찾는다.
2. 약별 복약 안내는 e약은요·허가정보·HIRA·DUR 근거로 만든다.
3. 생활습관 안내는 약이 아니라 진단명별로 만든다. 질병관리청 국가건강정보포털의 생활습관 관련 섹션을 우선하고, 없으면 저장된 학회 지침 요약을 사용한다.
4. 한 처방에 여러 진단명이 있으면 각각 별도 생활습관 가이드로 생성한다.
5. 생성 결과와 `source_refs`를 DB 및 캐시에 저장한다.

## Langfuse score를 사람의 말로 설명하면

이 점수는 의료진의 임상 평가나 정답 채점이 아니다. 추가 LLM 호출 없이 결과에 들어 있는 항목 수, 출처 수, 검토 플래그, 문자열 패턴을 계산한 운영용 휴리스틱이다. 모두 0~1 범위이며 높을수록 현재 규칙상 양호하다는 뜻이다.

### 공통 점수

- `groundedness`: 답변이나 가이드가 검색한 근거와 출처를 충분히 갖고 있는지 본다.
- `source_relevance`: 검색 문서와 출처가 질문·약품·진단 결과에 연결됐는지 본다.
- `completeness`: 필요한 안내, 주의사항, 생활습관 항목이 얼마나 채워졌는지 본다.
- `medical_safety`: 임의 중단·임의 증량 같은 위험 문구는 감점하고, 의사·약사 상담 안내와 검토 필요 상태를 반영한다.
- `patient_clarity`: 답변 길이, 문장 구조, 어려운 용어, 환자용 요약 존재 여부로 읽기 쉬운지를 추정한다.

### 처방 가이드 전용 점수

- `drug_coverage`: 유효한 OCR 약품 중 실제 자동 가이드가 생성된 비율이다.
- `citation_coverage`: 약별 안내와 생활습관 안내 수에 비해 연결된 출처가 충분한지 본다.
- `drug_source_match`: 생성된 약품명과 출처의 약품명이 일치하는지 본다.
- `required_section_coverage`: 각 약의 복약 안내와 주의사항 필드가 채워졌는지 본다.

점수가 낮으면 `rag_quality_gate.py`가 검색 실패, 근거 부족, 필수 안내 누락, OCR/약품 매핑 실패, 의료 안전 검토 필요 같은 원인 후보로 분류한다. 개선 후보는 평가 데이터셋에서 회귀 여부를 확인하지만, 통과하더라도 운영 반영은 자동 승인하지 않고 사람 승인을 기다린다.

### 다른 관찰 지점

- 챗봇: RAG 문서 수 70%, 응답 출처 수 20%, DUR 근거 수 10%를 중심으로 근거 점수를 만든다.
- 약 상세정보: 주의사항·부작용·상호작용·DUR 존재 여부와 약품명 매칭도를 본다.
- OCR: 추출 약품 수, 진단명 존재, 낮은 신뢰도 및 오탐 힌트 비율을 본다.

따라서 높은 점수는 “규칙상 근거와 필드가 잘 채워졌다”는 신호이지, 내용이 의학적으로 완전히 옳다는 보증은 아니다.
