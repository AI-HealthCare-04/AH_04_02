# 사용자 요구사항 정의서 v11 → v12(final) Revision Log

## 기준과 편집 원칙

- 기준 코드: `dev` 7f4fcd1
- 병합 전 최종 반영 범위: PR #153 알림함 논리 삭제
- v12(final)의 버전과 파일명은 유지했다.
- 본문은 개발·검수 지표로 바로 사용할 수 있도록 최종 제공 기능만 수록했다.
- 개발 과정의 상태를 뜻하는 `미구현`, `부분`, `보류`, `확인 필요` 표현은 본문에서 사용하지 않는다.

## 구조 변경

1. `백로그`, `구현완료`, `미구현·보류` 시트를 삭제했다. 최종 요구사항은 공통 및 역할별 시트에만 두고, 제외된 범위는 이 revision log에서 관리한다.
2. 안내, 프로젝트 목적, 용어집, 핵심 흐름을 처음 읽는 사람의 업무 흐름에 맞게 다시 작성했다.
3. `복약관리 대상자`, `보호자·지원인력`, `처방전 목록`, `복약 주의사항`, `생활습관 가이드`, `알림함`, `논리 삭제`로 용어를 통일했다.
4. 남은 요구사항의 상태는 모두 `완료`로 통일하고, 코드 근거와 검수 기준을 현재 동작에 맞게 정리했다.
